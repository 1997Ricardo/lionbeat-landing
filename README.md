# LIONBEAT — Performance System

Landing page desarrollada con HTML5, CSS3 y JavaScript ES6+ vanilla.

## Estructura

- `index.html` — estructura, contenido y SEO.
- `css/style.css` — identidad visual, responsive y animaciones.
- `js/script.js` — menú móvil, scroll, reveal animations y año dinámico.
- `assets/lionbeat-logo.png` — logo oficial proporcionado.
- `robots.txt` — directrices para buscadores.
- `sitemap.xml` — sitemap inicial.

## Uso

Abre `index.html` directamente en el navegador o utiliza Live Server en VS Code.

## Antes de publicar

1. Sustituir `https://www.lionbeat.com/` por el dominio real.
2. Sustituir `info@lionbeat.com` por el email real.
3. Añadir los enlaces reales de Instagram/YouTube.
4. Sustituir las fotografías demo por imágenes propias/licenciadas.
5. Añadir resultados reales de atletas cuando estén disponibles.
6. Generar favicon y versiones optimizadas del logo.
7. Revisar textos legales, cookies y privacidad según el sistema de captación que se implemente.
